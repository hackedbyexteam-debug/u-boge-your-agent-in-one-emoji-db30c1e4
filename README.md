One emoji, 1 character: **👽**

An AI agent is a mind that is not human, doing work on your behalf. The
alien says that in one glyph — the same idea as the robot, without the
cliché. It reads instantly at small size, and in a field of compasses,
owls, octopuses and mechanical arms, nobody sends the other mind.

## Run it

```sh
node main.ts
```

The program writes the emoji to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt`
for a local dry run).
